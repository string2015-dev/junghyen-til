# 261105 멀티모달 RAG — 요약 생성 정리

> 지난 시간에 PDF에서 꺼낸 **텍스트 / 표 / 이미지**를 **검색용 요약문(색인 카드)** 으로 바꾸는 단계.
> → **LCEL 요약 체인 → 텍스트·표 요약(LLM) → 이미지 Base64 변환 → 이미지 요약(VLM) → 검증·토큰 측정 → 저장**
> (벡터 저장소 구축·검색·답변 생성은 다음 단계)

```
텍스트 ──┐
  표   ──┼──▶ 요약문 생성(LLM / VLM) ──▶ 검색용 색인(색인 카드)
이미지 ──┘
```

## 📌 오늘의 키워드

| 키워드 | 한 줄 설명 |
|---|---|
| **요약 기반 검색** | 검색은 **요약**(임베딩)으로, 답변은 **원본**으로. 요약과 원본을 짝지어 보관 |
| **LCEL 파이프 (`\|`)** | 왼쪽 칸의 출력이 오른쪽 칸의 입력이 되는 컨베이어 벨트 문법 |
| **ChatPromptTemplate** | `{element}` 자리표시자가 있는 프롬프트 템플릿 |
| **StrOutputParser** | `AIMessage` 객체 → 순수 문자열로 꺼내기 |
| **`.batch()` / `max_concurrency`** | 여러 건 동시 요청 / 동시 요청 상한 (너무 높으면 `RateLimitError`) |
| **temperature=0** | 같은 입력엔 같은 출력. 요약은 창의성보다 **일관성** |
| **압축률** | 요약 길이 ÷ 원본 길이. 작을수록 많이 줄인 것 (참고: 5~20%) |
| **VLM** (Vision Language Model) | 이미지를 이해하는 모델 (`gpt-4o-mini`) |
| **Base64** | 이진 데이터(이미지)를 64개 ASCII 문자로 바꾸는 인코딩. 그림을 문자열 상자에 포장 |
| **멀티모달 메시지** | `HumanMessage` 한 개 안에 텍스트 조각 + 이미지 조각을 리스트로 전달 |
| **data URL 접두사** | `data:image/jpeg;base64,` + Base64 문자열 |
| **영어 프롬프트 + 한국어 출력 지시** | 프롬프트는 영어, 마지막 줄에 "한국어(Hangul)로 작성" |
| **육안 검증** | 그림과 요약문을 나란히 놓고 눈으로 대조 (가장 중요한 단계) |
| **tiktoken** | OpenAI 토큰화를 로컬에서 재현. 비용 = 토큰 수 × 단가 |
| **pickle** | 파이썬 객체를 파일로 저장/복원 (냉동 → 해동) |
| **상수(대문자 변수)** | `PROJECT_ROOT`처럼 대문자 = 바뀌지 않는 공용 값이라는 약속 |
| **LLaVA / Ollama** | (참고) 로컬 오픈소스 VLM 대안. 노션에 있으나 수업은 OpenAI로 진행 |

## 1. 요약을 왜 하나? (요약의 핵심 방식)

- 이미지·표는 그 자체로는 임베딩·검색이 안 됨 → **텍스트 요약으로 바꿔서** 임베딩
- 요약은 디테일이 날아감 → **검색은 요약으로, 답변 생성은 원본으로**
- 비유: 도서관 **색인 카드**(요약)로 찾고, 서가에서 **진짜 책**(원본)을 꺼냄
- 그래서 이미지마다 ① 요약문(검색용) ② Base64 원본(답변용)을 **같은 순서**로 저장 → 나중에 짝짓기

## 3. 텍스트·표 요약 (LLM)

**LCEL 체인 = 컨베이어 벨트 4칸**

| 칸 | 받는 것 | 내보내는 것 |
|---|---|---|
| `{"element": lambda x: x}` | 문자열 | `{"element": 문자열}` |
| `prompt` | 딕셔너리 | 완성된 프롬프트 |
| `model` | 프롬프트 | `AIMessage` |
| `StrOutputParser()` | `AIMessage` | 순수 문자열 |

```python
summarize_chain = {"element": lambda x: x} | prompt | model | StrOutputParser()
text_summaries  = summarize_chain.batch(texts, {"max_concurrency": 2})
```

- `.invoke(x)` = 1건 / `.batch([...])` = 여러 건 동시 처리
- 프롬프트는 **영어로 작성 + 마지막 줄에 한국어 출력 지시** (정확도·토큰 효율 면에서 권장)
- 텍스트는 `summarize_texts=True`일 때만 요약, `False`면 원문 그대로 사용

### 압축률 (요약 품질 지표)

- 압축률 = **요약 길이 ÷ 원본 길이 × 100** → 숫자가 작을수록 더 많이 줄인 것
- 너무 높으면 요약이 안 된 것, 너무 낮으면 정보가 빠졌을 수 있음 (참고: **5~20%**)
- 압축률을 **낮춘다** (10→5%) = 더 짧게, 핵심만 / **높인다** (10→30%) = 더 길게, 세부 내용까지
- 경제 보고서처럼 **세부 수치가 필요한 문서는 압축률을 높여** 디테일을 남김
- **선택 기준 = 실제 질문으로 검색이 잘 되는지**
- 이번 실습: 원본 1000자 → 요약 432자 = **43.2%** (목표보다 높음)
  - 프롬프트에 길이 제한이 없고 마크다운 기호(`**`, `-`)도 글자 수에 포함된 영향
  - 개선: 프롬프트에 "3문장 이내" 같은 길이 지시 추가

### 표 요약이 비어 있다면?

비어 있어도 **정상일 수 있음**.
1. 표가 **그림으로 그려져** 있어 `Table`이 아닌 **이미지로 추출**됨 (→ 이미지 요약 단계에서 처리)
2. 지난 추출에서 `strategy="hi_res"` 누락

- 이번 PDF는 표 35개 → 요약 35개 생성
- 원본과 요약을 `zip`으로 나란히 출력해 비교. 표 중에는 **목차 같은 의미 낮은 표**도 섞여 있음

## 4. 이미지 요약 (VLM)

### 4-1. Base64 인코딩

```python
def encode_image(image_path):
    with open(image_path, "rb") as f:                        # 파일 읽기 (바이너리)
        return base64.b64encode(f.read()).decode("utf-8")    # bytes → str
```

- API는 **문자열만** 주고받음 → 그림(바이너리)을 문자열로 포장해서 전송
- 흐름: `파일 읽기("rb")` → `b64encode()` (bytes) → `.decode("utf-8")` (str)
- **인코딩을 쓰는 이유**
  - **호환성 유지** : 다양한 환경에서 일관되게 처리
  - **전송 안전성** : 텍스트 기반 프로토콜로 이미지를 안전하게 전송
  - **손상 방지** : 이진 데이터를 텍스트로 바꿔 전송·저장할 때의 손실 예방
- 확인: 알파벳·숫자가 뒤섞인 긴 문자열이 나오면 성공 (이번 첫 이미지: 길이 145,068)

### 4-2. 멀티모달 메시지로 VLM 호출

```python
chat = ChatOpenAI(model="gpt-4o-mini", max_tokens=1024)
msg = chat.invoke([HumanMessage(content=[
    {"type": "text", "text": prompt},                                              # 지시문 조각
    {"type": "image_url", "image_url": {"url": f"data:image/jpeg;base64,{img_base64}"}},  # 이미지 조각
])])
return msg.content
```
- 교재의 `gpt-4-vision-preview`는 **지원 종료** → `404 model not found` → **`gpt-4o-mini`** 사용
- `data:image/jpeg;base64,` 접두사가 꼭 필요

### 4-3. 이미지 요약 프롬프트 개선 (폴더 전체 요약용)

테스트 프롬프트("간결하게 요약")보다 **구체적인 규칙**을 주면 품질이 올라감.
- 문서 유형(표/막대/선그래프 등)과 제목 먼저 파악
- 핵심 지표, 열·행 헤더, X/Y축 이름, 추세·수치 추출
- "이 이미지는…" 같은 군더더기 서두 금지, 핵심 데이터로 바로 시작
- 3~4문장, 검색 키워드 중심, **한국어로 출력**

### 4-4. 400 오류와 사전 검증

- `unsupported image`, 잘못된 Base64 등은 **400 오류**로 돌아옴
- 오류가 난 뒤 고치기보다 **요청 보내기 전에 검증 로직**으로 걸러내는 것이 맞음

```python
# (예시) 요청 전 사전 검증 — 수업 코드 아님, 개념 확인용
def is_valid_image(path):
    return path.suffix.lower() in (".jpg", ".jpeg", ".png") and path.stat().st_size > 0
```

## 6. 토큰 측정 & 저장

```python
enc = tiktoken.encoding_for_model("gpt-4o-mini")
input_tokens  = sum(len(enc.encode(t)) for t in texts_2k_token)   # 원문 토큰
```

## 8. 생각해 볼 질문 정리

- **이미지를 왜 텍스트로 요약하나?** → 이 구조는 텍스트 임베딩 기반이라 이미지는 그대로 검색 불가. 텍스트 요약으로 바꿔야 임베딩·검색됨
- **요약만 저장하고 원본을 버리면?** → 디테일(정확한 수치·그림)이 사라져 답변 품질 저하. VLM에 다시 줄 원본 이미지도 없음
- **`max_concurrency`를 100으로 올리면?** → 동시 요청 과다로 `RateLimitError`(429) 발생. 실패·재시도로 오히려 느려지거나 중단

## 9. 자주 나는 에러

| 증상 | 원인 | 해결 |
|---|---|---|
| `AuthenticationError` | `.env` 키 오타 / `load_dotenv()` 누락 | 공백·따옴표 제거 |
| `404 model not found` | 지원 종료 모델 사용 | `gpt-4o-mini` |
| `400` (unsupported image 등) | 이미지 형식·Base64 문제 | **요청 전 사전 검증** |
| `RateLimitError` | 동시 요청 과다 | `max_concurrency` 낮추기 (5→2) |
| `FileNotFoundError: extracted.pkl` | 지난 시간 저장 셀 미실행 | 지난 노트북 마지막 셀 재실행 |
| `IndexError` | `figures/`에 이미지 없음 | `figures_dir` 경로 확인 |
| 요약이 영어로 나옴 | 한국어 출력 지시 누락 | 프롬프트 마지막 줄 확인 |
| `NameError` | 앞 셀 미실행 | 위에서부터 순서대로 재실행 |

## 11. 전체 흐름 코드 (한눈에 보기)

```python
# =====================================================================
# 멀티모달 RAG ② 요약 생성 전체 흐름
#   extracted.pkl ─▶ 텍스트·표 요약(LLM) ──────────────┐
#   figures/*.jpg ─▶ Base64 ─▶ 이미지 요약(VLM) ───────┼▶ 검증·토큰 측정 ─▶ summaries.pkl
# =====================================================================
import os, time, pickle, base64
from pathlib import Path
from dotenv import load_dotenv
import tiktoken
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.messages import HumanMessage
from langchain_openai import ChatOpenAI

# ---------------------------------------------------------------------
# [1] 준비 ─ 경로(상수) 설정 + API 키 로드
# ---------------------------------------------------------------------
PROJECT_ROOT = Path.cwd().parent if Path.cwd().name in ["invest", "practice"] else Path.cwd()
MAX_CONCURRENCY = 2                      # 대문자 = 상수. 동시 요청 수 (RateLimitError 나면 더 낮추기)

load_dotenv(PROJECT_ROOT / ".env")       # .env 파일의 키를 환경변수로 등록
openai_api_key = os.getenv("OPENAI_API_KEY")
if not openai_api_key:                   # 키가 없으면 즉시 중단
    raise ValueError("OpenAI API 키가 없습니다. .env 파일을 확인하세요")
print(f"API 키 로드 완료: {openai_api_key[:7]}...")   # 앞 7자만 출력 (유출 방지)

# ---------------------------------------------------------------------
# [2] 지난 시간 결과 복원 ─ pickle (냉동 보관 → 해동)
# ---------------------------------------------------------------------
with open(PROJECT_ROOT / "data" / "processed" / "extracted.pkl", "rb") as f:
    data = pickle.load(f)
tables = data["tables"]                  # 표(문자열 리스트)
texts_2k_token = data["texts_2k_token"]  # 토큰 기준으로 재분할한 텍스트 청크
figures_dir = PROJECT_ROOT / "practice" / "figures"   # 추출된 이미지 폴더

# ---------------------------------------------------------------------
# [3] 텍스트·표 요약 ─ LCEL 체인(컨베이어 벨트) + batch
# ---------------------------------------------------------------------
def generate_text_summaries(texts, tables, summarize_texts=False):
    # 영어 프롬프트 + 마지막 줄에 한국어 출력 지시. {element} 자리에 원문이 들어감
    prompt_text = """You are an assistant tasked with summarizing tables and text for retrieval.
These summaries will be embedded and used to retrieve the raw text or table elements.
Give a concise summary of the table or text that is well optimized for retrieval.
Table or text: {element}
The summary should be written in Korean (Hangul)."""

    prompt = ChatPromptTemplate.from_template(prompt_text)     # 템플릿 적용 칸
    model = ChatOpenAI(temperature=0, model="gpt-4o-mini")     # temperature=0 → 일관된 요약

    # 입력 포장 → 템플릿 → LLM 호출 → 문자열로 꺼내기
    summarize_chain = {"element": lambda x: x} | prompt | model | StrOutputParser()

    text_summaries, table_summaries = [], []
    if texts and summarize_texts:        # 텍스트도 요약하는 경우
        text_summaries = summarize_chain.batch(texts, {"max_concurrency": MAX_CONCURRENCY})
    elif texts:                          # 요약 안 하면 원문 그대로 사용
        text_summaries = texts
    if tables:                           # 표는 있으면 항상 요약
        table_summaries = summarize_chain.batch(tables, {"max_concurrency": MAX_CONCURRENCY})
    return text_summaries, table_summaries

start = time.time()

# ---------------------------------------------------------------------
# [4] 이미지 → Base64 ─ API는 문자열만 받으므로 그림을 '문자열 상자'에 포장
# ---------------------------------------------------------------------
def encode_image(image_path):
    with open(image_path, "rb") as f:                          # 바이너리로 읽기
        return base64.b64encode(f.read()).decode("utf-8")      # bytes → str

# ---------------------------------------------------------------------
# [5] 이미지 요약(VLM) ─ 텍스트 조각 + 이미지 조각을 한 메시지에 담아 호출
# ---------------------------------------------------------------------
def image_summarize(img_base64, prompt):
    chat = ChatOpenAI(model="gpt-4o-mini", max_tokens=1024)    # gpt-4-vision-preview는 지원 종료
    msg = chat.invoke([HumanMessage(content=[
        {"type": "text", "text": prompt},                      # 지시문
        {"type": "image_url",                                  # 이미지 (data URL 접두사 필수)
         "image_url": {"url": f"data:image/jpeg;base64,{img_base64}"}},
    ])])
    return msg.content

def generate_img_summaries(path):
    img_base64_list, image_summaries = [], []   # 두 리스트의 순서가 같아야 나중에 요약↔원본 짝짓기 가능

    prompt = """You are an expert AI assistant that summarizes document images (tables, charts, graphs, text) for a semantic retrieval system.
The summary will be embedded and used to retrieve this raw image.
1. Identify the document type and its main title or topic.
2. Extract key metrics, table headers, X/Y axis labels, and prominent trends or data points.
3. Capture any critical conclusions or text visible in the image.
4. Do not start with generic phrases like "이 이미지는"; start directly with the core data.
5. Keep it to 3-4 dense sentences focused on searchable keywords.
6. The output MUST be written in Korean (Hangul)."""

    for image_file in sorted(os.listdir(path)):                # 이름순 정렬 → 순서 고정
        if image_file.endswith((".jpg", ".jpeg", ".png")):     # 이미지 확장자만 처리
            b64 = encode_image(os.path.join(path, image_file))
            img_base64_list.append(b64)                        # ① 원본(답변 생성 때 VLM에 다시 전달)
            image_summaries.append(image_summarize(b64, prompt))  # ② 요약(검색용)
    return img_base64_list, image_summaries
```
