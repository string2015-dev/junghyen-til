# 멀티모달 RAG ③ — 다중 벡터 검색기 + 최종 체인 정리

> 요약문으로 **검색**하고, 같은 번호표(`doc_id`)로 **원본**(텍스트·표·이미지)을 꺼내서 멀티모달 LLM에게 넘긴다.

---

## 📌 오늘의 키워드

| 키워드 | 한 줄 설명 |
| --- | --- |
| `strategy="hi_res"` | `partition_pdf()`가 레이아웃을 분석해 정밀하게 추출하는 옵션. **빠뜨리면 표·이미지 추출 정밀도가 크게 떨어진다** (복습) |
| **MultiVectorRetriever** | 요약으로 검색하고 원본을 돌려주는 검색기 |
| `vectorstore` (Chroma) | **색인 카드 서랍.** 요약문 임베딩을 넣는 곳 → **검색**용 |
| `docstore` (InMemoryStore) | **서가.** 원본(텍스트·표·Base64 이미지)을 넣는 곳 → **전달**용 |
| `id_key = "doc_id"` | **청구기호(번호표).** 요약과 원본을 잇는 키 |
| `uuid.uuid4()` | 겹치지 않는 고유 ID 생성. `str()`로 감싸 문자열로 바꿔 쓴다 |
| `add_documents()` / `mset()` | 요약 → vectorstore에 저장 / 원본 → docstore에 (id, 원본) 쌍으로 저장 |
| Base64 정규식 | `^[A-Za-z0-9+/]{100,}={0,2}$` → 검색 결과에서 이미지와 텍스트를 구분 |
| `data:image/jpeg;base64,` | Base64 이미지를 LLM에 넘길 때 앞에 붙이는 접두사 |
| `HumanMessage(content=[...])` | 이미지 + 텍스트를 한 메시지에 담는 멀티모달 메시지 |
| **LCEL** (`\|`) | `RunnableLambda`, `RunnablePassthrough`, `StrOutputParser`를 파이프로 연결해 체인 구성 |
| **Before / After** | 같은 질문을 텍스트 전용 RAG vs 멀티모달 RAG에 던져 차이를 증거로 남김 |
| `OllamaLLM` | 로컬 오픈소스 모델(llama3.1:8b)로 번역만 맡겨 비용 절감 (선택) |
| `__이름__` | 밑줄 두 개가 붙은 것은 **파이썬/시스템이 제공하는 것** (예: `__init__`, `__pycache__`) |

## 1. 전체 구조 한눈에 보기

```
질문 ──▶ 요약으로 검색 ──▶ 번호표(doc_id) 읽기 ──▶ 원본 꺼내기 ──▶ 멀티모달 LLM ──▶ 답변
         (vectorstore)     (metadata)            (docstore)       (gpt-4o-mini)
```

> **비유: 도서관.** 사서는 책을 다 읽고 찾지 않는다. **색인 카드(요약)로 검색**하고, 찾으면 **서가에서 진짜 책(원본)을 꺼내** 준다.

**핵심 한 줄: 요약과 원본에 같은 번호표를 붙인다.**

## 3. 검색기 만들기

```python
vectorstore = Chroma(collection_name="multimodal_rag",
                     embedding_function=OpenAIEmbeddings(model="text-embedding-3-small"))
store = InMemoryStore()
id_key = "doc_id"
retriever = MultiVectorRetriever(vectorstore=vectorstore, docstore=store, id_key=id_key)
```

- langchain **1.x**와 **0.3**에서 import 위치가 다르다 → `try / except ImportError`로 둘 다 시도

| 클래스 | langchain 1.x | langchain 0.3 |
| --- | --- | --- |
| MultiVectorRetriever | `langchain_classic.retrievers.multi_vector` | `langchain.retrievers.multi_vector` |
| InMemoryStore | `langchain_core.stores` | `langchain.storage` |

- `InMemoryStore`는 **메모리에만 저장** → 커널 재시작 시 사라짐 (실서비스는 파일 / Redis)

## 4. 요약 ↔ 원본 같은 ID로 짝짓기 (가장 중요)

```
요약 0 ── a1b2... ── 원본 0
요약 1 ── c3d4... ── 원본 1      같은 순번(i) = 같은 번호표
```

| 무엇을 | 어디에 | 메서드 | 왜 |
| --- | --- | --- | --- |
| 요약문 (Document + metadata `doc_id`) | `vectorstore` | `add_documents()` | 검색용 (TODO 1) |
| 원본 (id, 원본) 쌍 | `docstore` | `mset(list(zip(ids, 원본)))` | 전달용 (TODO 2) |

- 텍스트 / 표 / 이미지 각각 **데이터가 있을 때만** 저장
- ⚠️ **이 셀을 두 번 실행하면 중복 저장** → 검색기 셀부터 다시 실행

## 5. 검색 테스트

```python
found = retriever.invoke(query)
```

**retriever 내부 동작**
1. 질문을 임베딩으로 변환
2. vectorstore에서 비슷한 **요약문** 검색
3. 요약의 `metadata["doc_id"]` 읽기
4. docstore에서 그 번호표의 **원본** 반환

- ✅ 확인: 결과에 **이미지(Base64)가 최소 1건**
- 질문은 **그래프·표를 봐야만 답할 수 있는 것**이어야 Before/After 차이가 난다
  - 좋은 예: "그래프에 나타난 2023년 추세를 설명해줘"
  - 나쁜 예: "이 문서는 무엇에 관한 것인가요?"

---

## 6. 검색 결과를 이미지 / 텍스트로 분리

Base64 문자열은 **영문·숫자·`+`·`/`만 길게 이어지고 끝에 `=`가 0~2개** → 정규식으로 구분

```python
def split_image_text_types(docs):
    b64_images, texts = [], []
    for doc in docs:
        doc = doc.page_content if isinstance(doc, Document) else doc   # ← 꼭 doc에 다시 대입
        if re.match(r"^[A-Za-z0-9+/]{100,}={0,2}$", doc):
            b64_images.append(doc)
        else:
            texts.append(doc)
    return {"images": b64_images, "texts": texts}
```

## 7. 최종 멀티모달 체인

```
{검색 + 질문}  →  img_prompt_func  →  멀티모달 LLM  →  StrOutputParser
  재료 모으기      메시지로 조립        답변 생성        문자열로 꺼내기
```

- `img_prompt_func`: **이미지 먼저**(모델이 그림을 먼저 보게) → 지시문 + 질문 + 참고 텍스트
- 이미지 URL: `f"data:image/jpeg;base64,{image}"` (TODO 4, **쉼표 뒤 공백 없음**)
- 체인 3번 칸 = `model` (TODO 5)
- 지시문: "자료에 없는 내용은 모른다고 답하세요" → 환각 방지

## 8. Before / After 비교 (과제 7점)

텍스트 전용 RAG는 **이미지·표를 뺀 것 말고 모든 조건이 같게** 만든다 (같은 임베딩·모델·지시문, `k=4`).

**수업 결과 예시** — 질문: "과거 데이터 모의실험에서 상환 차수별 횟수와 빈도율은? 1차 상환 비율은?"

| | 답변 |
| --- | --- |
| **BEFORE** (텍스트 전용) | "자료에 해당 정보가 없어 알 수 없습니다." |
| **AFTER** (멀티모달) | 1차 5009회(97.21%), 2차 80회(1.55%), 3차 64회(1.24%) … → **1차 상환 비율 97.21%** |

**차이가 난 이유:** 그 숫자들은 **표/이미지 안에만** 있었다. 텍스트 RAG는 그 데이터를 버리고, 멀티모달 RAG는 원본 이미지를 LLM에 직접 보여줬다.

> 💡 차이가 안 나면 → 질문이 텍스트로도 답 가능한 것. **그래프에만 있는 정보**를 묻도록 바꾼다.

## 🧭 오늘의 전체 흐름 — 한 번에 보는 코드

```python
# ============================================================
# 0. 준비: 모듈 import + 환경변수 + 앞 단계 결과 복원
# ============================================================
import os, re, time, uuid, pickle
from pathlib import Path
from dotenv import load_dotenv

# .env 가 있는 폴더를 프로젝트 루트로 자동 탐색 (현재 폴더 → 상위 폴더 순서)
PROJECT_ROOT = next(
    (p for p in [Path.cwd(), *Path.cwd().parents] if (p / ".env").exists()),
    Path.cwd(),                                   # 못 찾으면 현재 폴더
)
load_dotenv(PROJECT_ROOT / ".env")                # 루트의 .env 를 정확히 지정해서 로드
if not os.getenv("OPENAI_API_KEY"):
    raise ValueError("OPENAI_API_KEY가 없습니다. .env를 확인하세요")

processed = PROJECT_ROOT / "data" / "processed"

# 추출 결과 (partition_pdf(strategy="hi_res") 로 뽑아 둔 것)
with open(processed / "extracted.pkl", "rb") as f:
    d1 = pickle.load(f)
texts, tables, texts_2k_token = d1["texts"], d1["tables"], d1["texts_2k_token"]

# 요약 결과 (텍스트·표·이미지 요약 + 이미지 Base64 원본)
with open(processed / "summaries.pkl", "rb") as f:
    d2 = pickle.load(f)
text_summaries  = d2["text_summaries"]
table_summaries = d2["table_summaries"]
image_summaries = d2["image_summaries"]
img_base64_list = d2["img_base64_list"]


# ============================================================
# 1. 다중 벡터 검색기: 서랍(vectorstore) + 서가(docstore) + 청구기호(id_key)
# ============================================================
try:    # langchain 1.x
    from langchain_classic.retrievers.multi_vector import MultiVectorRetriever
    from langchain_core.stores import InMemoryStore
except ImportError:   # langchain 0.3
    from langchain.retrievers.multi_vector import MultiVectorRetriever
    from langchain.storage import InMemoryStore
from langchain_chroma import Chroma
from langchain_openai import OpenAIEmbeddings, ChatOpenAI
from langchain_core.documents import Document

vectorstore = Chroma(                              # 요약문 임베딩 → 검색용
    collection_name="multimodal_rag",
    embedding_function=OpenAIEmbeddings(model="text-embedding-3-small"),
)
store = InMemoryStore()                            # 원본 보관 → 전달용 (메모리라 재시작 시 사라짐)
id_key = "doc_id"                                  # 요약과 원본을 잇는 번호표 이름

retriever = MultiVectorRetriever(vectorstore=vectorstore, docstore=store, id_key=id_key)


# ============================================================
# 2. 요약과 원본에 "같은 번호표"를 붙여 저장  ← 오늘의 핵심
# ============================================================
def add_documents(retriever, doc_summaries, doc_contents):
    # 원본 1개당 고유 ID 1개 (uuid 객체 → 문자열)
    doc_ids = [str(uuid.uuid4()) for _ in doc_contents]
    # 요약문을 Document 로 감싸고, metadata 에 번호표를 붙인다
    summary_docs = [
        Document(page_content=s, metadata={id_key: doc_ids[i]})
        for i, s in enumerate(doc_summaries)
    ]
    retriever.vectorstore.add_documents(summary_docs)            # 요약 → 서랍 (검색)
    retriever.docstore.mset(list(zip(doc_ids, doc_contents)))    # (번호표, 원본) → 서가 (전달)

# 데이터가 있을 때만 저장 (⚠️ 두 번 실행하면 중복!)
if text_summaries:  add_documents(retriever, text_summaries,  texts_2k_token)
if table_summaries: add_documents(retriever, table_summaries, tables)
if image_summaries: add_documents(retriever, image_summaries, img_base64_list)
print("색인된 요약 수:", len(vectorstore.get()["ids"]))


# ============================================================
# 3. 검색 결과를 이미지(Base64) / 텍스트로 분리
# ============================================================
B64_PATTERN = r"^[A-Za-z0-9+/]{100,}={0,2}$"      # Base64 문자만 100자 이상 + 끝에 = 0~2개

def split_image_text_types(docs):
    b64_images, texts_out = [], []
    for doc in docs:
        doc = doc.page_content if isinstance(doc, Document) else doc   # Document 면 문자열 꺼내기
        (b64_images if re.match(B64_PATTERN, doc) else texts_out).append(doc)
    return {"images": b64_images, "texts": texts_out}


# ============================================================
# 4. 멀티모달 프롬프트 조립 + 최종 체인 (LCEL)
# ============================================================
from langchain_core.messages import HumanMessage
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnableLambda, RunnablePassthrough

INSTRUCTION = ("아래 자료를 근거로 질문에 한국어로 답하세요.\n"
               "자료에 없는 내용은 모른다고 답하세요.\n\n")

def img_prompt_func(data_dict):
    messages = []
    # 1) 이미지 먼저 → 접두사 "data:image/jpeg;base64," 를 붙여 URL 형태로
    for image in data_dict["context"]["images"]:
        messages.append({"type": "image_url",
                         "image_url": {"url": f"data:image/jpeg;base64,{image}"}})
    # 2) 지시문 + 질문 + 참고 텍스트
    formatted_texts = "\n".join(data_dict["context"]["texts"])
    messages.append({"type": "text",
                     "text": INSTRUCTION
                             + f"질문: {data_dict['question']}\n\n"
                             + f"참고 텍스트:\n{formatted_texts}"})
    return [HumanMessage(content=messages)]        # 이미지+텍스트가 담긴 한 개의 메시지

model = ChatOpenAI(model="gpt-4o-mini", temperature=0, max_tokens=1024)   # 눈 달린 모델

chain = (
    {
        "context": retriever | RunnableLambda(split_image_text_types),  # 질문 → 검색 → 분리
        "question": RunnablePassthrough(),                              # 질문은 그대로 전달
    }
    | RunnableLambda(img_prompt_func)   # 메시지 조립
    | model                             # 답변 생성
    | StrOutputParser()                 # AIMessage → 문자열
)


# ============================================================
# 5. 질의 실행
# ============================================================
query = "그래프/표를 봐야만 답할 수 있는 질문을 적으세요"
start = time.time()
answer = chain.invoke(query)
print(f"{time.time() - start:.1f}초\nQ: {query}\n{'-'*70}\n{answer}")


# ============================================================
# 6. Before / After: 텍스트 전용 RAG 와 비교 (조건은 이미지·표 빼고 동일)
# ============================================================
text_only_store = Chroma(
    collection_name="text_only_rag",
    embedding_function=OpenAIEmbeddings(model="text-embedding-3-small"),
)
text_only_store.add_texts(texts_2k_token)                      # 텍스트 원본만 넣음
text_retriever = text_only_store.as_retriever(search_kwargs={"k": 4})

text_prompt = ChatPromptTemplate.from_template(
    INSTRUCTION + "질문: {question}\n\n참고 텍스트:\n{context}"
)
text_only_chain = (
    {"context": text_retriever | RunnableLambda(lambda ds: "\n".join(d.page_content for d in ds)),
     "question": RunnablePassthrough()}
    | text_prompt | model | StrOutputParser()
```
