# 파이썬 객체지향 기초: class · object · 생성자 · 소멸자 정리

## 📌 오늘의 키워드

| 키워드 | 한 줄 정리 |
|---|---|
| 프로그래밍 언어 | 인간과 컴퓨터가 소통(데이터·명령을 주고받기)하기 위해 정해 둔 언어 |
| 기계어 / 어셈블리어 | 0과 1의 이진 코드 / 기계어를 기호로 쓴 것 (`ADD A B`) → **저급 언어** |
| 고급 언어 | 변수 이름·일상 표현으로 작성 (C, Java, Python) → 결국 기계어로 변환되어 실행 |
| 컴파일러 | 코드를 **한 번에** 기계어로 변환 (C, Java) |
| 인터프리터 | 코드를 **한 줄씩** 기계어로 변환 (Python, PHP, Ruby) |
| 절차지향 vs 객체지향 | 순서대로 명령 나열 vs 사물(객체)을 만들고 객체끼리 기능을 호출 |
| class | 속성과 동작을 정의해 **표준화한 설계도 = 데이터 타입** (붕어빵 틀) |
| object / instance | class를 기반으로 메모리에 실체화된 객체 (붕어빵) |
| attribute (속성) | 객체가 가진 데이터 → 변수와 비슷 |
| method (메서드) | 객체가 하는 동작 → 클래스 안의 함수 |
| `self` | 지금 메서드를 부른 **그 객체 자신**(을 가리키는 참조) |
| `__init__` (생성자, constructor) | 객체가 **만들어질 때** 자동 실행 → 초기값 세팅 |
| `__del__` (소멸자, destructor) | 객체가 **사라질 때** 자동 실행 → 뒷정리 |
| 참조(이름표) | 변수는 객체에 붙은 이름표. 이름표가 0개가 되면 객체 소멸 |
| overriding / overloading | 상속받은 메서드 재정의 / 같은 이름에 매개변수만 다르게 정의 |

---

## 1. 프로그래밍 언어론

- **프로그래밍 언어** = 인간이 컴퓨터에게 명령을 전달하기 위한 언어
- CPU가 실제로 이해하는 것은 **기계어(0과 1)** 뿐 → CPU가 수행 가능한 명령 묶음을 **instruction set**(더하기, 저장, if, return 등)이라 함
- 저급 언어(기계어, 어셈블리어) ↔ 고급 언어(C, Java, Python)
- 고급 언어는 결국 기계어로 바뀌어야 실행됨

| 변환 방식 | 방법 | 대표 언어 |
|---|---|---|
| 컴파일러 | 전체를 **한 번에** 변환 | C, Java |
| 인터프리터 | **한 줄씩** 변환 | Python, PHP, Ruby |

## 2. 절차지향 vs 객체지향

**질문: 두 코드의 차이는?**

```python
print_string("Happy Coding")   # 그냥 함수 호출
"Happy Coding".split()          # 문자열 "객체"가 가진 메서드 호출 → 객체.메서드()
```

- **절차지향**: "냉장고 문을 연다 → 코끼리를 넣는다 → 문을 닫는다" 처럼 순서대로 명령 (C, 파스칼, 코볼…)
- **객체지향**: 코끼리 설계도·냉장고 설계도(class)를 만들고 → 객체를 만든 뒤 → 객체의 기능을 서로 호출
- Java/C++은 객체지향이 필수, **파이썬은 선택**. 이미 쓰고 있던 `객체.메서드()`(예: `str.split()`)가 바로 객체지향 문법

### 객체지향 프로그램 작성 순서
1. 클래스 설계 (attribute와 method 구성)
2. 설계한 클래스를 코드로 작성
3. 클래스를 기반으로 필요한 객체 생성
4. 객체의 attribute와 method를 조작해 프로그램 수행

## 3. class와 object

| 구분 | class | object |
|---|---|---|
| 역할 | 설계도 / 틀 | 설계도로 만든 실물 |
| 만드는 법 | `class Dog:` | `my_dog = Dog()` |
| 개수 | 보통 1개 | 원하는 만큼 여러 개 |
| 비유 | 붕어빵 틀 | 붕어빵 |

- 클래스 이름은 **단어 첫 글자 대문자** (`Dog`, `ChatBot`, `BankAccount`)
- 내용이 없으면 `pass`
- 같은 틀로 만들어도 **서로 다른 객체** → `my_dog is your_dog` 는 `False`
- 속성 접근: `객체.속성` (점 `.` 은 "~의"라고 읽기) / `dir(객체)` 로 속성·메서드 목록 확인
- 한 객체의 속성을 바꿔도 **다른 객체는 영향 없음**

## 4. method와 self

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):                    # 첫 매개변수는 항상 self
        print(f"{self.name}: 멍멍!")   # self.name = "나의" name
```

- `self` = 메서드를 **부른 객체 자신의 참조**
- `my_dog.bark()` 는 내부적으로 `Dog.bark(my_dog)` 로 바뀌어 실행 → `my_dog` 이 자동으로 `self` 에 들어감
- 그래서 인자가 필요 없는 메서드도 **`self` 는 반드시** 적어야 함
- class 코드를 읽을 때는 `class` 정의 범위(들여쓰기 블록) 전체를 봐야 속성·메서드를 다 파악할 수 있음

## 5. 생성자 `__init__`

- 객체가 만들어지는 **순간 자동 실행** (밑줄 **2개씩**: `__init__`)
- 실행 순서: `Dog("초코", 3)` → ① 빈 객체 생성 → ② `__init__(self, "초코", 3)` 자동 호출 → ③ 변수에 저장
- 생성자가 클래스를 "적재"하는 것이 아니라, **새로 만들어진 객체의 초기값을 채워 넣는 역할**
- **기본값**: `def __init__(self, name="이름없음", age=0)` → `Dog()`, `Dog("보리")` 모두 가능
- **키워드 인자**: `Dog(age=2, name="콩이")` → 순서 상관없음
- 기본값 없는 인자를 빠뜨리면 → `TypeError: __init__() missing 1 required positional argument`
- 생성자 안에서 **값 검사**도 가능 (나이가 음수면 0으로)

### 💡 `name` vs `self.name` — 좀 더 풀어서

| 표기 | 정체 | 수명 | 비유 |
|---|---|---|---|
| `name` | `__init__` 의 **매개변수(지역 변수)** | `__init__` 이 끝나면 사라짐 | 창구에 낸 신청서 |
| `self.name` | 객체에 붙은 **인스턴스 속성** | **객체가 살아있는 동안** 유지 | 내 서류함에 보관된 서류 |

- `self.name` 이 "계속 유지된다"는 점에서 정적 변수처럼 느껴지지만, **정적 변수(static)는 아님**
  - `self.name` → 객체마다 **따로** 가짐 (초코의 name, 보리의 name이 다름)
  - 모든 객체가 **공유**하는 값은 클래스 바로 아래 적는 **클래스 변수** (`class Dog: name = "이름없음"`) 쪽이 static에 더 가까움

## 6. 소멸자 `__del__`

- 객체가 메모리에서 **사라질 때 자동 실행** → 연결 끊기, 파일 닫기, 로그 남기기 등 뒷정리
- 핵심 규칙: **객체를 가리키는 변수(이름표)가 0개가 되면** 객체 소멸

| `__del__` 실행 상황 | 예시 |
|---|---|
| ① `del` 로 직접 삭제 | `del my_dog` |
| ② 변수가 다른 객체를 가리킴 | `my_dog = Dog("새로운")` |
| ③ 함수 종료로 지역 변수 소멸 / 프로그램 종료 | 함수 안에서 만든 객체 |

### 이름표가 2개인 경우

```python
a = Dog("초코")
b = a            # 새 객체 X → 같은 객체에 이름표를 하나 더 붙임
print(a is b)    # True

del a            # 이름표 1개 남음 → 객체는 살아있음
del b            # 이름표 0개 → 이때 __del__ 실행
```

- `b = a` 는 객체를 복사하는 게 아니라 **같은 객체를 가리키는 참조(주소)를 복사**한 것
- 파이썬은 엄밀히 "call by value"가 아니라 **객체 참조를 전달(call by object reference / assignment)** 하는 방식이라고 부름
- `del` 은 객체를 지우는 게 아니라 **이름표(변수)를 떼는 것**

## 7. 참고: overriding vs overloading

| 용어 | 뜻 | 관계 |
|---|---|---|
| **overriding** | 부모에게 받은 메서드를 자식이 **재정의** | 상속 관계 |
| **overloading** | 같은 이름 메서드를 **매개변수 개수·타입만 다르게** 여러 개 정의 | 같은 클래스 |

- 파이썬은 같은 이름으로 메서드를 두 번 정의하면 **나중 것이 덮어씀** → overloading 대신 **기본값 매개변수**로 해결
- (참고) 수업 중 언급: **FastAPI** = 파이썬 웹 프레임워크 (클래스·객체 문법이 많이 쓰임)

## 8. 자주 하는 실수

| 에러 | 원인 | 해결 |
|---|---|---|
| `bark() takes 0 positional arguments but 1 was given` | 메서드에 `self` 누락 | `def bark(self):` |
| `NameError: name 'name' is not defined` | 메서드 안에서 `self.` 없이 사용 | `self.name` |
| `AttributeError: 'Dog' object has no attribute 'name'` | 속성을 만든 적 없음 / 오타 | `__init__` 에서 설정 |
| `__init__() missing 1 required positional argument` | 생성 시 값 덜 넣음 | `Dog("초코", 3)` |
| `my_dog.bark` 로 썼는데 아무 일도 안 일어남 | 괄호 `()` 누락 | `my_dog.bark()` |

## 9. 🔁 오늘 배운 전체 흐름 한눈에 보기

```python
# =====================================================================
# 1) 클래스 설계: "속성(데이터) + 메서드(동작)"를 하나로 묶은 설계도
#    - 클래스 이름은 첫 글자 대문자
# =====================================================================
class ChatBot:
    # 클래스 변수: 모든 ChatBot 객체가 "공유"하는 값 (static에 가까움)
    total_bots = 0

    # -----------------------------------------------------------------
    # 2) 생성자 __init__: 객체가 만들어지는 순간 자동 실행
    #    - self    : 지금 만들어지고 있는 "그 객체 자신"
    #    - name    : 매개변수 (__init__ 이 끝나면 사라지는 임시값)
    #    - greeting: 기본값이 있는 매개변수 → 안 넣으면 "안녕하세요!"
    # -----------------------------------------------------------------
    def __init__(self, name, greeting="안녕하세요!"):
        self.name = name            # 인스턴스 속성: 객체마다 따로 보관
        self.greeting = greeting
        self.history = []           # 객체마다 별도의 대화 기록 리스트
        ChatBot.total_bots += 1     # 클래스 변수는 클래스 이름으로 접근
        print(f"[{self.name}] {self.greeting}")

    # -----------------------------------------------------------------
    # 3) 메서드: 첫 매개변수는 항상 self
    #    bot_a.say("hi")  ==  ChatBot.say(bot_a, "hi")
    # -----------------------------------------------------------------
    def say(self, user_message):
        reply = f"기억할게요 → '{user_message}'"
        print(f"[{self.name}] {reply}")
        self.history.append((user_message, reply))   # "나의" 기록에만 저장

    def show_history(self):
        for i, (msg, reply) in enumerate(self.history, start=1):
            print(f"  {i}. 사용자: {msg} / 봇: {reply}")

    # -----------------------------------------------------------------
    # 4) 소멸자 __del__: 객체를 가리키는 이름표가 0개가 될 때 자동 실행
    #    → 뒷정리(연결 종료, 로그 남기기 등)
    # -----------------------------------------------------------------
    def __del__(self):
        print(f"[{self.name}] 안녕히 계세요. 오늘 대화는 {len(self.history)}개였어요.")


# =====================================================================
# 5) 객체 생성: 하나의 설계도로 여러 객체(인스턴스)를 찍어냄
#    - self 는 빼고 나머지 인자만 넣는다
# =====================================================================
bot_a = ChatBot("코코")                        # greeting 기본값 사용
bot_b = ChatBot("모모", greeting="반가워요!")   # 키워드 인자로 지정
print(bot_a is bot_b)                         # False → 같은 틀, 다른 객체

# =====================================================================
# 6) 객체.메서드() / 객체.속성 으로 프로그램 수행
# =====================================================================
bot_a.say("파이썬 공부 중이야")
bot_a.say("class 가 뭐야?")
bot_b.say("안녕?")

bot_a.show_history()          # 코코의 기록만 2개
bot_b.show_history()          # 모모의 기록만 1개 → 서로 섞이지 않음
print("만든 봇 수:", ChatBot.total_bots)   # 2 (클래스 변수는 공유)

# =====================================================================
# 7) 참조(이름표)와 소멸
#    - same = bot_a : 객체 복사 X, 같은 객체에 이름표 하나 추가
# =====================================================================
same = bot_a
print(same is bot_a)          # True

del bot_a                     # 이름표 1개 남음 → 아직 소멸 안 됨
print("--- bot_a 이름표를 뗐지만 same 이 남아 있음 ---")
del same                      # 이름표 0개 → 여기서 코코의 __del__ 실행

bot_b = ChatBot("새봇")        # bot_b 가 새 객체를 가리킴 → 모모의 __del__ 실행
print("끝")                    # 프로그램 종료 시 새봇의 __del__ 실행
```
